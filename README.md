# Hardcore Death Penalty

Полностью **серверный** мод для хардкора: после смерти игрок остаётся на сервере,
но становится **наблюдателем** на реальное время, а когда срок заканчивается —
возвращается в игру и теряет сердце, которое можно вернуть ежедневными входами.

* Minecraft **26.3**
* NeoForge **26.3.0.90** и новее в ветке 26.3
* Java **25**
* Устанавливается **только на сервер** — клиенту мод не нужен.

## Что делает мод

1. **Игрок умирает** → сервер записывает смерть, и при возрождении игрок попадает
   в **режим наблюдателя (spectator)**. Заходить можно в любой момент, но играть нельзя.
2. **3 реальных дня** (72 часа) игрок остаётся наблюдателем. Как только срок истёк,
   мод автоматически возвращает его в игру (даже если он в этот момент онлайн),
   ставит режим, который был до смерти, и телепортирует на точку возрождения.
3. **При возвращении забирается 1 сердце** (20 → 18 HP).
4. Чтобы вернуть сердце, нужно **заходить на сервер каждый день 7 дней подряд**.
   День считается засчитанным, если игрок зашёл хотя бы раз в течение дня
   (в том числе если он не выходил с сервера через полночь).
5. Пропустил день — серия сбрасывается и начинается заново (настраивается).
6. Дальше цикл повторяется: каждые 7 дней серии возвращают одно сердце.
   Умереть можно несколько раз — каждая смерть забирает ещё одно сердце,
   но ниже настраиваемого минимума (по умолчанию 1 сердце) здоровье не падает.

Пока идёт срок наблюдения, дни в серию **не** засчитываются — серия начинается
с того дня, когда игрок вернулся в игру.

## Установка

1. Скачать `hardcore_death_penalty-1.0.0.jar`.
2. Положить его в папку `mods` **сервера** (клиенту не нужно).
3. Запустить сервер один раз — создастся конфиг
   `config/hardcore_death_penalty-synced.toml`.
4. Настроить под себя и перезапустить сервер.

> Конфиг общий для сервера. Если нужны отдельные настройки для конкретного мира,
> положите копию в `<мир>/syncedconfig/hardcore_death_penalty-synced.toml` — она
> переопределит общий файл.

## Конфиг

```toml
[spectator]
    enabled = true
    durationDays = 3
    durationMinutes = 0
    returnToSpawn = true
    announceDeath = true
    deathAnnouncement = "..."

[hearts]
    loseHeartOnDeath = true
    heartsPerDeath = 1
    minHearts = 1
    recoveryDays = 7
    resetStreakOnMissedDay = true

[day]
    dayStartHour = 0
    timeZone = "system"

[messages]
    spectatorStart = "..."
    spectatorJoin = "..."
    punishmentEnded = "..."
    heartLost = "..."
    streakProgress = "..."
    heartRestored = "..."
```

Основные параметры:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `spectator.enabled` | `true` | Отправлять погибших в режим наблюдателя |
| `spectator.durationDays` | `3` | Сколько реальных дней длится режим наблюдателя |
| `spectator.durationMinutes` | `0` | Если больше 0 — длительность в минутах (переопределяет `durationDays`, удобно для тестов) |
| `spectator.returnToSpawn` | `true` | Телепортировать на точку возрождения при возврате в игру |
| `hearts.loseHeartOnDeath` | `true` | Забирать сердца за смерть |
| `hearts.heartsPerDeath` | `1` | Сколько сердец забирать за смерть |
| `hearts.minHearts` | `1` | Минимум сердец, ниже которого нельзя опуститься |
| `hearts.recoveryDays` | `7` | Сколько дней подряд нужно заходить, чтобы вернуть одно сердце |
| `hearts.resetStreakOnMissedDay` | `true` | Сбрасывать серию при пропуске дня |
| `day.dayStartHour` | `0` | Час, с которого начинается новый день |
| `day.timeZone` | `system` | Часовой пояс, например `Europe/Moscow` |

Все тексты сообщений настраиваются. Поддерживаются цветовые коды `§` и плейсхолдеры:

* `{player}`, `{days}`, `{hours}`, `{minutes}`, `{until}`, `{deaths}`, `{hearts_per_death}`
* `{hearts}`, `{max_hearts}`, `{lost}`, `{required}`, `{streak}`

## Команды

Требуют прав оператора (permission level 2).

| Команда | Описание |
| --- | --- |
| `/hdp` | Справка по командам |
| `/hdp status` | Показать свой статус |
| `/hdp status <игрок>` | Статус игрока (работает и для офлайн-игроков) |
| `/hdp end <игрок>` | Досрочно вернуть игрока в игру |
| `/hdp sethearts <игрок> <0-10>` | Задать количество потерянных сердец |
| `/hdp reset <игрок>` | Полностью сбросить штрафы игрока |

## Сборка

Нужна Java 25.

```bash
./gradlew build
```

Готовый jar появится в `build/libs/hardcore_death_penalty-1.0.0.jar`.
Сборка также запускается в GitHub Actions (`.github/workflows/build.yml`);
собранный jar автоматически коммитится в папку `release/`.

## Как это устроено внутри

* `LivingDeathEvent` — фиксирует смерть, срок наблюдателя и потерю сердца.
* `PlayerRespawnEvent` — через тик после возрождения переводит игрока в наблюдателя
  (или возвращает ему нормальный режим, если срок уже истёк). Это же исправляет
  ванильное поведение хардкора, где игрок остаётся наблюдателем навсегда.
* `PlayerLoggedInEvent` — применяет штраф и считает ежедневный вход.
* Фоновый «сторож» (раз в секунду) — возвращает игроков в игру по истечении срока,
  страхует режим наблюдателя и считает смену дня для тех, кто не выходит с сервера.
* `SavedData` в оверворлде (`world/data/hardcore_death_penalty/penalties.dat`) хранит
  состояние по UUID игрока: срок наблюдателя, потерянные сердца, серию входов,
  число смертей и режим игры для восстановления.

## Частые вопросы

**Клиенту нужен мод?**
Нет. Мод не добавляет предметов, блоков и сетевых пакетов, поэтому клиент может
заходить без него (в том числе ванильный клиент NeoForge).

**Игрок умер и вышел из игры. Что будет?**
Штраф сохранён в данных мира. При следующем входе он увидит экран смерти,
после нажатия «Возродиться» станет наблюдателем, а когда срок истечёт — вернётся
в игру. Принудительно возрождать его из кода не нужно, поэтому сессия не ломается.

**Сервер упал сразу после смерти?**
Ничего страшного: срок и штраф уже записаны в данные мира, сторож применит их
при следующем запуске.

**Можно ли сделать только режим наблюдателя, без потери сердец?**
Да: `hearts.loseHeartOnDeath = false`.

**Как выдать игроку сердце обратно вручную?**
`/hdp sethearts <игрок> <0-10>` — команда задаёт количество потерянных сердец,
`/hdp reset <игрок>` полностью сбрасывает штрафы.
