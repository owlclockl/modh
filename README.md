# Hardcore Death Penalty

Полностью **серверный** мод для хардкора: смерть = дезбан на реальное время + потеря сердец,
которые можно вернуть ежедневными входами.

* Minecraft **26.3**
* NeoForge **26.3.0.90** и новее в ветке 26.3
* Java **25**
* Устанавливается **только на сервер** — клиенту мод не нужен.

## Что делает мод

1. **Игрок умирает** → сервер записывает смерть и кикает его.
2. **3 реальных дня** (72 часа) игрок не может зайти на сервер.
   При попытке зайти он видит сообщение с оставшимся временем и датой возврата.
3. Когда бан закончился, игрок заходит и **теряет 1 сердце** (20 HP → 18 HP).
4. Чтобы вернуть сердце, нужно **заходить на сервер каждый день 7 дней подряд**.
   День считается засчитанным, если игрок зашёл хотя бы раз в течение дня
   (в том числе если он не выходил с сервера через полночь).
5. Пропустил день — серия сбрасывается и начинается заново (настраивается).
6. Дальше цикл повторяется: каждые 7 дней серии возвращают одно сердце.
   Умереть можно несколько раз — каждое смерть забирает ещё одно сердце,
   но ниже настраиваемого минимума (по умолчанию 1 сердце) здоровье не падает.

Сервер сам принудительно возрождает погибшего игрока перед киком, поэтому
хардкоровый режим «навсегда спектатор» не срабатывает: после истечения бана игрок
спавнится живым на своей точке возрождения. Вещи при смерти выпадают как обычно
(если в мире не включён `keepInventory`).

## Установка

1. Скачать `hardcore_death_penalty-1.0.0.jar`.
2. Положить его в папку `mods` **сервера** (клиенту не нужно).
3. Запустить сервер один раз — создастся конфиг
   `config/hardcore_death_penalty-synced.toml`.
4. Настроить под себя и перезапустить сервер.

> Конфиг общий для сервера. Если нужны отдельные настройки для конкретного мира,
> положите копию в `<мир>/syncedconfig/hardcore_death_penalty-synced.toml` — она
> переопределит общий файл.
> Мод не добавляет предметов, блоков и сетевых пакетов, поэтому обычные клиенты
> NeoForge/ванильные клиенты подключаются без него.

## Конфиг

```toml
[ban]
    enabled = true
    durationDays = 3
    announceDeath = true
    deathAnnouncement = "..."
    kickMessage = "..."

[hearts]
    loseHeartOnDeath = true
    heartsPerDeath = 1
    minHearts = 1
    recoveryDays = 7
    resetStreakOnMissedDay = true

[day]
    dayStartHour = 0
    timeZone = "system"

[messages]
    heartLost = "..."
    streakProgress = "..."
    heartRestored = "..."
```

Основные параметры:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `ban.enabled` | `true` | Включён ли дезбан |
| `ban.durationDays` | `3` | Длительность бана в реальных днях |
| `hearts.loseHeartOnDeath` | `true` | Забирать сердца за смерть |
| `hearts.heartsPerDeath` | `1` | Сколько сердец забирать за смерть |
| `hearts.minHearts` | `1` | Минимум сердец, ниже которого нельзя опуститься |
| `hearts.recoveryDays` | `7` | Сколько дней подряд нужно заходить, чтобы вернуть одно сердце |
| `hearts.resetStreakOnMissedDay` | `true` | Сбрасывать серию при пропуске дня |
| `day.dayStartHour` | `0` | Час, с которого начинается новый день |
| `day.timeZone` | `system` | Часовой пояс, например `Europe/Moscow` |

Все тексты сообщений настраиваются. Поддерживаются цветовые коды `§` и плейсхолдеры:

* `{player}`, `{days}`, `{hours}`, `{minutes}`, `{until}`, `{deaths}`, `{hearts_per_death}`
* `{hearts}`, `{max_hearts}`, `{lost}`, `{required}`, `{streak}`

## Команды

Требуют прав оператора (permission level 2).

| Команда | Описание |
| --- | --- |
| `/hdp status` | Показать свой статус |
| `/hdp status <игрок>` | Статус игрока (работает и для офлайн-игроков) |
| `/hdp unban <игрок>` | Снять бан |
| `/hdp sethearts <игрок> <0-10>` | Задать количество потерянных сердец |
| `/hdp reset <игрок>` | Полностью сбросить штрафы игрока |

## Сборка

Нужна Java 25.

```bash
./gradlew build
```

Готовый jar появится в `build/libs/hardcore_death_penalty-1.0.0.jar`.
Сборка также запускается в GitHub Actions (`.github/workflows/build.yml`),
готовый архив можно скачать со страницы запусков (Artifacts).

## Как это устроено внутри

* `LivingDeathEvent` — фиксирует смерть, бан и потерю сердца, затем на следующем
  тике возрождает игрока и кикает с сообщением о бане.
* `PlayerLoggedInEvent` — проверяет бан, применяет штраф и считает ежедневный вход.
* `PlayerRespawnEvent` — повторно применяет модификатор максимального здоровья
  (атрибуты не переносятся на новую сущность игрока).
* `ServerTickEvent.Post` — раз в 10 секунд проверяет смену дня для игроков, которые
  не выходят с сервера.
* `SavedData` в оверворлде (`world/data/hardcore_death_penalty/penalties.dat`) хранит
  состояние по UUID игрока: срок бана, потерянные сердца, серию входов, число смертей.

## Частые вопросы

**Клиенту нужен мод?**
Нет. Мод не добавляет предметов, блоков и сетевых пакетов, поэтому клиент может
заходить без него (в том числе ванильный клиент NeoForge).

**Что если сервер упадёт сразу после смерти?**
Состояние игрока сохраняется в данных мира. После перезапуска при входе мод
сам доиграет принудительное возрождение и применит штраф.

**Можно ли сделать бан на 3 дня, но без потери сердец?**
Да: `hearts.loseHeartOnDeath = false`.

**Как выдать игроку сердце обратно вручную?**
`/hdp sethearts <игрок> <0-10>` — команда задаёт количество потерянных сердец,
`/hdp reset <игрок>` полностью сбрасывает штрафы.
